# Эпик — источники данных

**Приоритет:** P2  
**Статус:** каркас (yahoo/moex + catalog metrics)  
**Связано:** [[Event Contract#market.history.candle]], [[Universe selection]], [[Эпик — Universe selection]]

---

## Цель

История для бэктеста и **дешёвых метрик catalog** (dollar volume, ATR%, price) перед screener.  
Legacy `get_finance_data.py` не импортируем в v2-path.

---

## Источники

| Источник | Статус | Приоритет |
|----------|--------|-----------|
| Yahoo (`yfinance`) | **v2 adapter** | основной |
| MOEX (`aiomoex`) | **v2 adapter** | основной для TQBR |
| Alpha Vantage | legacy only | **низкий** — был единственным найденным тогда; не блокер |
| Google / Finam | broken | backlog |
