## Цель

Durable persistence в хост-слое через **переносимый** `cb_storage`:  
мульти-backend, hot buffer, **hot reroute** без рестарта.

In-memory `CandleStore` = hot path Engine.  
`storage_service` = durable mirror событий.

---

## Backends

| Backend | Роль |
|---------|------|
| `sqlite` | local durable (default) |
| `duckdb_local` | локальная аналитика свечей |
| `jsonl_local` | spill / debug |
| `parquet_local` | cold archive |
| `clickhouse_main` | high-ingest analytics (server) |
| `chdb_local` | embedded CH (не Windows-first) |
| `postgres` | shared journal / multi-instance |
| `cockroach` | distributed PG-wire (HA) |
